# دفتر | Daftar

تطبيق أندرويد مجاني لإدارة طلبات التجار الصغار.

## المميزات
- العربية والإنجليزية والفرنسية والإسبانية.
- حفظ الطلبات محليًا والعمل دون إنترنت.
- إضافة الطلبات والبحث عنها وتغيير حالتها.
- إنشاء فواتير PDF ومشاركتها.
- تصميم بسيط واحترافي.

## البناء
سيتم إعداد GitHub Actions لبناء نسخة APK قابلة للتثبيت.
